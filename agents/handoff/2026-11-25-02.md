## Gotchas
- GitHub's GraphQL was degraded during #11: `gh pr create`, `gh pr merge` and `scripts/task.sh` failed. Use REST:
  `gh api -X POST repos/atirelli3/bonito/pulls`, `-X PUT …/pulls/N/merge -f merge_method=squash`, `-X DELETE
  …/git/refs/heads/<branch>`. Closing keywords still close issues; check githubstatus.com first.
- GateGuard denies the first edit or write of each file once, even after the facts: state them, retry the same call. In a
  batch only the denied call fails: check which landed (a half-applied batch deleted `not_yet` and left its caller).
- The edit tools turn `\u202e` in the text you send into the raw character (rustc refused the source). Write Rust escapes
  as `\u{202e}`, or edit through python with doubled backslashes, and count raw characters afterwards.
- Review agents that run kuna with a relative `-o` create folders in the repo root (`./-x` appeared): tell them to use
  absolute paths and check `git status` after the reviews. `cargo test | grep` can hide the summary: use `tail -2`.
- Sleeps over ~60 s are blocked: poll in short calls. pty drivers (python `pty`, `XDG_CACHE_HOME` on a temp dir to keep the
  real cache clean) lived in the scratchpad and are gone after a reboot.
